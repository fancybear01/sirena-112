# Контракт Go Media <-> Python AI

## Назначение

Контракт описывает только голосовой поток одной уже созданной учебной сессии.
Управление звонком остаётся в Go Media, бизнес-состояние — в Kotlin Core.

## Подготовка

1. Core создаёт AI-сессию и передаёт Python разрешённый сценарный контекст.
2. Python возвращает `aiSessionId`.
3. Core отправляет Media команду `call.start` с `sessionId`, `aiSessionId` и
   SIP-адресом.
4. После ответа абонента Media открывает WebSocket:
   `/internal/v1/voice/{aiSessionId}?sessionId={sessionId}`.

Неизвестный, завершённый или не соответствующий `sessionId` идентификатор
должен приводить к отказу в открытии соединения.

### Создание AI-сессии

`POST /ai/voice/sessions`

```json
{
  "sessionId": "0199d7b6-0000-7000-8000-000000000002",
  "scenario": { "id": "80c14c89-f2b7-527a-bd6f-268cdc3d4a11": "...сценарий целиком" }
}
```

Ответ `201 Created`:

```json
{
  "aiSessionId": "ai-34b9f696-55ed-403f-980b-fd3653f9a6fc",
  "sessionId": "0199d7b6-0000-7000-8000-000000000002",
  "scenarioId": "80c14c89-f2b7-527a-bd6f-268cdc3d4a11",
  "speech": "vosk+piper",
  "speechAvailable": true,
  "speechSimulated": false,
  "notice": null
}
```

Поля `speechAvailable` и `speechSimulated` показывают режим работы речи
до начала звонка. Если модели не настроены, поток годится только для проверки
транспорта: транскрипта не будет, вместо него придёт `error` с кодом
`speech.unavailable`. Если вместо моделей работают подмены, каждый
`transcript.final` помечен `simulated: true` - выдавать такой текст
за распознанную речь нельзя.

Освобождение сессии: `DELETE /ai/voice/sessions/{aiSessionId}`.

Коды закрытия WebSocket: `4404` - пара идентификаторов не найдена,
`4409` - к сессии уже подключён другой поток.

## Транспорт MVP

- один двунаправленный WebSocket на звонок;
- текстовые WebSocket-фреймы содержат UTF-8 JSON;
- бинарные WebSocket-фреймы содержат raw PCM;
- базовый формат: mono, signed 16-bit little-endian, 16 kHz;
- Media отвечает за преобразование RTP-кодека в базовый формат и обратно;
- рекомендуемый размер аудиофрейма — 20 мс, то есть 640 байт;
- порядок бинарных фреймов внутри одного соединения является порядком аудио.

Перед первым бинарным фреймом Media отправляет:

```json
{
  "type": "stream.start",
  "sessionId": "0199d7b6-0000-7000-8000-000000000002",
  "aiSessionId": "ai-0199d7b6",
  "audio": {
    "encoding": "pcm_s16le",
    "sampleRate": 16000,
    "channels": 1,
    "frameDurationMs": 20
  }
}
```

## Направление Media -> AI

- бинарные PCM-фреймы речи обучающегося;
- `stream.start` — параметры и идентификаторы потока;
- `input.flush` — завершить текущий фрагмент речи;
- `response.cancel` — прервать текущую реплику AI при перебивании;
- `stream.stop` — штатно завершить поток.

Пример контрольного сообщения:

```json
{
  "type": "input.flush",
  "sequence": 42,
  "timestamp": "2026-09-15T12:00:05.420Z"
}
```

## Направление AI -> Media

- бинарные PCM-фреймы ответа AI-абонента;
- `transcript.partial` и `transcript.final`;
- `caller.state_changed`;
- `response.started` и `response.completed`;
- `error`.

Пример финального транскрипта:

```json
{
  "type": "transcript.final",
  "sequence": 43,
  "text": "Назовите адрес происшествия",
  "startedAtMs": 1240,
  "endedAtMs": 2870,
  "simulated": false
}
```

Отметки времени считаются по количеству принятого звука, а не по часам:
один и тот же разговор даёт одинаковые значения, и занятие можно разобрать
с преподавателем.

Ограничения потока: фрагмент речи не длиннее 30 секунд, к одной AI-сессии
одновременно подключается один поток, число сессий ограничено.

Media оборачивает значимые сообщения AI в стандартный конверт из
`contracts/events.md`, создаёт `eventId` и отправляет их в Core. Python не
вызывает Core во время голосового потока.

## Завершение и ошибки

- закрытие звонка приводит к `stream.stop` и закрытию WebSocket;
- закрытие AI-потока не должно оставлять RTP-мост или ARI-канал без очистки;
- Media публикует в Core `system.error`, если AI недоступен или нарушил формат;
- повторное подключение допускается с теми же идентификаторами, пока AI-сессия
  активна; политика повтора и очистки принадлежит Media;
- аудио и транскрипт не являются источником истины, пока Core не сохранил
  соответствующее событие.

## Что не входит в контракт

- создание и утверждение сценариев;
- управление Asterisk, SIP, ARI и RTP;
- доступ Go или Python к основной PostgreSQL;
- расчёт и сохранение итоговой оценки;
- карточный режим без звонка.
