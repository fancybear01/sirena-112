# Как работать с репозиторием

## Ветки

Изменения делаем в ветках формата:

```text
feature/{part}/{task-number}
```

Примеры:

```text
feature/core/5
feature/media/10
feature/ai/14
feature/web/2
```

Правила:

- только латиница в нижнем регистре, цифры и дефис в `{part}`;
- `{task-number}` — номер GitHub Issue без `#`;
- одна ветка соответствует одной задаче;
- ветка создаётся от актуального `main`.

## Pull Request

`main` защищён: прямой push и force-push запрещены. Изменения попадают в
`main` только через Pull Request с успешно пройденной проверкой `branch-name`
и как минимум одним одобрением.

Перед открытием PR:

1. Обновите ветку от `main`.
2. Выполните локальные тесты своего сервиса.
3. В описании PR укажите `Closes #номер-задачи`.
4. Не смешивайте несколько независимых задач в одном PR.
