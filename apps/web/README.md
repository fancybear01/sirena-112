# Web

Единое React/TypeScript-приложение для трёх ролей:

- `/admin` — пользователи, роли, состояние компонентов и настройки;
- `/teacher` — сценарии, назначения, запуск занятия и отчёты;
- `/student` — карточки, вызовы, результаты и история обучения.

До готовности Core API используются mock-данные, соответствующие
`contracts/openapi.yaml` и `contracts/events.md`.
