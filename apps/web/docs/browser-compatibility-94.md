# Проверка русского UX и совместимости браузеров (#94)

## Что проверяет автоматический smoke

Команда ниже запускает локальные mock API и Vite, открывает установленный Google
Chrome через DevTools Protocol и сохраняет реальные PNG без внешнего backend:

```powershell
node apps/web/scripts/browser-smoke.mjs
```

Smoke проверяет:

- вход и клавиатурный переход `Логин → Пароль`;
- основные экраны ADMIN, TEACHER и STUDENT;
- прямой вход на защищённый URL, восстановление каждой роли после обновления и
  перенаправление с чужого маршрута;
- отсутствие горизонтального переполнения и элементов управления за пределами
  viewport;
- доступность кнопки отправки карточки на узком экране;
- компоновку входа, преподавателя, обучающегося, администратора и итогового
  отчёта при 390×844;
- desktop-снимки при 1920×1080 и 1366×768.

## Исправленные UX-проблемы

- На узком экране кнопка «Отправить на оценку» больше не скрывается вместе с
  правой частью фиксированной полосы служб.
- Таблица учётных записей превращается в читаемые карточки и не требует
  горизонтальной прокрутки.
- Формы администратора, создание сценариев, история и экспертная правка
  выстраиваются в одну колонку; действия остаются доступны.
- Технические статусы ролей, сессий, версий и источников показываются по-русски.
- Добавлены явные состояния загрузки, общий заметный `focus-visible` и увеличен
  мелкий текст рабочего места оператора без изменения desktop-компоновки АРМ-112.
