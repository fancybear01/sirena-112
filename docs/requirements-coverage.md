### Безопасность

| Требование | Реализация | Доказательство |
| --- | --- | --- |
| Шифрование браузерного канала | TLS 1.3, HSTS, TLS 1.0/1.1 отклоняются | `docs/tls.md`, `scripts/check_tls.py` |
| Разграничение доступа | RBAC на каждом методе, преподаватель видит только свою группу, студент — только своё занятие | `docs/auth-rbac.md` |
| Межсервисная аутентификация | отдельные Bearer-токены для Media, AI и расширений; кривой токен — отказ, а не падение | #120, `services/ai/tests/test_service_auth.py` |
| Аудит значимых действий | `auth_audit`: входы, выходы, роли, отказы; журнал экспертных правок оценки | миграции V2, V4 |
| Минимизация персональных данных | перечень хранимых данных; табло и API расширений не отдают имена, логины, карточки, транскрипты; автоматический поиск ПДн в файлах, ответах сервиса и журналах | `docs/security-data-review.md`, `scripts/check_personal_data.py` |
| Изолированный контур | все порты только на loopback, профиль отказывается стартовать на другом адресе | `docs/offline-full-stack.md` |
| Секреты не попадают в репозиторий и логи | `.env` и `certs/` в `.gitignore`, токены не пишутся в журнал | тесты монитора и AI |

## Качество и проверяемость

Каждый Pull Request проходит полный набор обязательных проверок без фильтров
по путям: тесты Core, AI, Web и Media, валидация контрактов и сквозной
`demo / smoke` — два полных занятия `1050602` через реальные Core и AI.

Запускаемые проверки, каждая печатает результат и возвращает ненулевой код
при расхождении:

| Проверка | Скрипт |
| --- | --- |
| сквозное карточное занятие | `scripts/smoke_card_1050602.py` |
| голосовой контракт Core–AI–Media | `scripts/smoke_voice_contract.py` |
| полный стек с голосом | `scripts/smoke_voice_stack.py` |
| нагрузка голосового тракта | `scripts/load_voice_stack.py` |
| форматы обмена и хранения | `scripts/check_formats.py` |
| backup и восстановление | `scripts/check_backup_restore.py` |
| TLS браузерного канала | `scripts/check_tls.py` |
| отказоустойчивость и восстановление за 30 с | `scripts/check_resilience.py` |
| минимизация персональных данных | `scripts/check_personal_data.py` |
| контракт API расширений | `scripts/ext_api_client.py` |
| покрытие требований | `scripts/check_coverage.py` |

## Как повторить сверку

```bash
python scripts/check_coverage.py
```

Скрипт берёт состояние задач из GitHub, сопоставляет с историей `main` и
печатает сводку.
