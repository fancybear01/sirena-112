# TLS для браузерного доступа

Часть задачи #89. Дата: 29.09.2026.

Шифрование браузерного канала дополняет RBAC, сервисные токены, аудит и
изоляцию контура на loopback - вместе они образуют защиту учебных данных.

## Что сделано

Шифрование канала «браузер - веб - Core». TLS завершается на том же nginx,
который отдаёт интерфейс, и оттуда запросы идут в Core по внутренней сети
compose.

| Проверено | Результат |
| --- | --- |
| версия протокола | TLS 1.3, шифр TLS_AES_256_GCM_SHA384 |
| TLS 1.0 и 1.1 | отклоняются |
| `/health` по HTTPS | 200 |
| API через шифрованный канал | 200 |
| `Strict-Transport-Security` | `max-age=31536000` |
| `X-Content-Type-Options` | `nosniff` |
| `X-Frame-Options` | `DENY` |
| профиль без TLS | не сломан, HTTP на 5173 работает |

Повторить:

```bash
python scripts/check_tls.py --url https://127.0.0.1:8443
```

## Как включить

```bash
sh scripts/make_tls_cert.sh
docker compose -f compose.yaml -f compose.tls.yaml up -d
```

Открывается на `https://127.0.0.1:8443`. Профиль без шифрования остаётся
на своём порту: `compose.tls.yaml` - наложение, а не замена. Так сделано
намеренно, чтобы демонстрация и CI не зависели от сертификатов.

## Сертификаты

В репозиторий не попадают: каталог `certs/` в `.gitignore`. В образ не
встраиваются - монтируются снаружи только для чтения.

| Файл | Права | Что это |
| --- | --- | --- |
| `certs/sirena.key` | 600 | закрытый ключ |
| `certs/sirena.crt` | 644 | сертификат |

`scripts/make_tls_cert.sh` выпускает самоподписанный на 397 дней. Срок
выбран не произвольно: браузеры не принимают серверные сертификаты со
сроком больше 398 дней.

SAN обязателен и он есть - `DNS:localhost`, `IP:127.0.0.1`. Без SAN
браузер отклонит сертификат, даже если согласиться на недоверенный.

**Смена.** Перевыпустить с `TLS_FORCE=yes` и перезапустить `web`. Скрипт
не перетирает существующий сертификат молча: без этого флага он показывает
срок действия и выходит.

**Контур заказчика.** Кладутся их файлы теми же именами, в конфигурации
менять нечего. Самоподписанный сертификат стенда браузер помечает
недоверенным - это ожидаемо и не является поломкой.

## Защита контура в целом

TLS закрывает единственный канал, который выходит за пределы машины, -
браузерный. Остальные меры работают вместе с ним:

| Мера | Где описана |
| --- | --- |
| роли ADMIN / TEACHER / STUDENT, доступ по группам, CSRF | `docs/auth-rbac.md` |
| отдельные Bearer-токены Media, AI и расширений | `docs/auth-rbac.md`, `docs/extension-api.md` |
| аудит входов, ролей, отказов и правок оценки | `docs/auth-rbac.md`, `docs/training-history.md` |
| внутренние порты только на 127.0.0.1 и в сети compose | `docs/offline-full-stack.md` |
| дампы и записи с правами 700/600 | `docs/backup-restore.md` |
| минимизация ПДн на табло и в API расширений | `docs/extension-api.md` |

Для контура заказчика подготовлено всё, чтобы подставить его сертификаты
теми же именами файлов без изменения конфигурации.
