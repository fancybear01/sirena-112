# Сводная аналитика обучения (#75)

`GET /api/teacher/analytics/summary` — read-only сводка для графиков Web. Она
строится из сохранённых отчётов Core (AI или резервная оценка Core), а не из
фиктивных чисел. Учитываются только карточные сессии `SCORED` с `endedAt` и
сохранённым отчётом. `COMPLETED` без оценки, `SCORING`, голосовые и отсутствующие
отчёты не учитываются. Повторная оценка заменяет отчёт по `sessionId`, поэтому
повторный запрос и replay не увеличивают число занятий.

Балл нормируется как `score / maxScore * 100` и ограничивается диапазоном
0–100; при `maxScore <= 0` считается 0. Среднее и медиана пустого набора —
`null`, остальные массивы пусты, а интервалы баллов содержат пять нулей.
`topErrors` считает невыполненные коды критериев рубрики не более одного раза
на занятие. `daily` группируется по дню `endedAt` в UTC; тип происшествия
берётся из эталона сценария (`classifierCode`, `incidentType`).

Пример формы ответа для Web (числа здесь иллюстрируют контракт, не production):

```json
{
  "completedSessions": 3,
  "averagePercent": 60.0,
  "medianPercent": 60.0,
  "scoreDistribution": [
    {"label": "0–20", "count": 1},
    {"label": ">20–40", "count": 0},
    {"label": ">40–60", "count": 1},
    {"label": ">60–80", "count": 0},
    {"label": ">80–100", "count": 1}
  ],
  "incidentTypes": [{"code": "1050602", "name": "Тип из классификатора", "count": 3}],
  "topErrors": [{"criterionCode": "ADDRESS", "count": 2}],
  "daily": [{"day": "2026-09-25", "count": 3, "averagePercent": 60.0}]
}
```

Ответ намеренно не содержит имён, контактов, адресов, карточек, транскриптов,
`sessionId` и свободного текста ошибок. До реализации RBAC endpoint сам по себе
не авторизует преподавателя: его следует публиковать только внутри демо-контура
или за ограничивающим доступ шлюзом, не на открытом внешнем табло.

При `CORE_STORAGE=in-memory` история пропадает после рестарта. При
`CORE_STORAGE=postgres` с Flyway сессии и отчёты сохраняются, поэтому сводка
восстанавливается после перезапуска Core; это не меняет отсутствие RBAC и
ограничение на публикацию API.
