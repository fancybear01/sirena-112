# Security task: персональные данные в записях учебных звонков

До использования записи с реальными людьми требуется отдельное согласование:

- основание и уведомление о записи, возможность отказа и политика удаления;
- точный срок хранения, роли и аудит каждого скачивания/удаления;
- шифрование тома и резервных копий, ключи и восстановление;
- запрет экспорта в публичные URL, проверка окружения и сетевой изоляции;
- порядок удаления записи при удалении сессии и после срока хранения;
- проверка журналов на отсутствие PCM, транскрипта и секретов.

Текущий код рассчитан на изолированный учебный контур с вымышленными
сценариями. Core закрывает скачивание без `CORE_AUTH_ENABLED=true` и проверяет
группу преподавателя. Эта задача не заменяет формальную оценку персональных
данных и политику организации.
