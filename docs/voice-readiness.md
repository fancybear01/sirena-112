# Готовность настоящего голоса на демо-стенде

Аудит по задаче #72. Проверялось, можно ли обещать живой разговор на той
машине, где будет демонстрация.

Дата проверки: 22.09.2026. Стенд: MacBook, Apple M3 Pro, 12 ядер, 18 ГБ.

## Вердикт

**Настоящий голос готов.** Распознавание и синтез работают на этой машине,
без интернета и без видеокарты, и укладываются в бюджет паузы с запасом вдвое.

| Что | Состояние |
| --- | --- |
| пакет `vosk` | установлен |
| модель `vosk-model-small-ru-0.22` | 87 МБ, работает |
| пакет `piper-tts` | установлен |
| голос `ru_RU-irina-medium` | 63 МБ, работает |

## Полный ход разговора

Прогон через работающий сервис: реальные записи речи оператора идут в поток,
Vosk распознаёт, абонент отвечает, Piper озвучивает.

```
речь: vosk+piper | подмена: false | notice: отсутствует

оператор : служба сто двенадцать здравствуйте слушаю вас
абонент  : Алло! Помогите, пожалуйста!
           ответ 2.84 с звука | весь ход 0.64 с

оператор : назовите адрес происшествия
абонент  : Учебный адрес, дом 1! Приезжайте скорее!
           ответ 4.16 с звука | весь ход 0.51 с

оператор : пострадавшие есть помощь нужна
абонент  : Пострадавших нет.
           ответ 1.36 с звука | весь ход 0.41 с
```

**От конца фразы оператора до готового ответа: 0.41-0.64 секунды.**
Бюджет 1.2 секунды, запас примерно вдвое.

Все три реплики распознаны верно, транскрипт помечен `simulated: false` -
это настоящее распознавание, а не подмена.

## Замеры по частям

| Модель | Загрузка | Работа | Доля от длительности |
| --- | --- | --- | --- |
| Vosk small ru 0.22 | 0.60 с | 0.33-0.39 с на фразу | 0.09-0.11 |
| Piper ru_RU-irina | 2.25 с | 0.05-0.18 с на реплику | около 0.03 |

Распознавание на этой машине быстрее, чем в замерах #13 на Kaggle
(0.09 против 0.21), - там было четыре ядра против двенадцати.

## Аудит нашёл дефект формата

Голос Piper звучит на **22050 Гц**, а контракт с Media требует **16000**.
Адаптер принимал запрошенную частоту, но игнорировал её и отдавал звук как есть.

Последствие было бы такое: Media получает 22050 Гц под видом 16000 и проигрывает
реплику медленнее и ниже по тону. На демонстрации это слышно сразу.

Исправлено: добавлен пересчёт частоты линейной интерполяцией. Стоит около
27 миллисекунд на длинной реплике, на бюджет не влияет, покрыто тестами.

На подменах такой дефект не всплывает: `SilenceSynthesizer` отдаёт ровно ту
частоту, которую попросили. Поэтому аудит на настоящих моделях и понадобился.

## Как скачать модели

Важная деталь: **сайт Vosk недоступен по IPv6**. Заголовки приходят мгновенно,
а тело файла не идёт - за восемь минут пришло 12 КБ из 44 МБ. По IPv4 файл
скачивается за минуту. Если загрузка виснет, добавьте `-4`:

```bash
mkdir -p models && cd models

curl -4 -L -o vosk-ru.zip \
  https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
unzip -q vosk-ru.zip && rm vosk-ru.zip

curl -L -o piper-irina.onnx \
  https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU/irina/medium/ru_RU-irina-medium.onnx
curl -L -o piper-irina.onnx.json \
  https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU/irina/medium/ru_RU-irina-medium.onnx.json
```

Зеркала Vosk на HuggingFace не подходят: все они в формате `sherpa-onnx`
(`encoder/decoder/joiner.onnx`), а пакет `vosk` ждёт свой каталог с `am/`,
`graph/` и `ivector/`.

Пакеты:

```bash
.venv/bin/python -m pip install vosk piper-tts
```

## Как включить

```bash
export AI_STT=vosk   AI_STT_MODEL=<путь>/models/vosk-model-small-ru-0.22
export AI_TTS=piper  AI_TTS_MODEL=<путь>/models/piper-irina.onnx

.venv/bin/python scripts/smoke_voice.py --real
```

Что проверить после запуска: ответ на создание голосовой сессии должен
показать `speech: vosk+piper`, `speechSimulated: false` и отсутствие `notice`.
Если там `unavailable` - модели не подхватились, смотрите пути.

Каталог `models/` в `.gitignore`: модели в репозиторий не попадают и в CI
не скачиваются. На каждой машине, где будет демонстрация, их нужно скачать
заранее - по сети во время показа этого лучше не делать.

## Требования к ресурсам

Модели вместе занимают 150 МБ на диске. Обе загружаются при старте сервиса,
суммарно около трёх секунд. Видеокарта не нужна, интернет после скачивания
не нужен.
