# Infrastructure

Локальная инфраструктура проекта:

- PostgreSQL 12+;
- Asterisk как локальный SIP-сервер (`infra/asterisk`, см. README там);
- контейнеры сервисов;
- локальные модели и записи разговоров;
- мониторинг, журналы и резервные копии.

Облачные зависимости не нужны для запуска демонстрационной сборки. Единый
офлайн-регламент, подготовка образов и моделей, health/readiness, обновление и
диагностика: [`../docs/offline-full-stack.md`](../docs/offline-full-stack.md).
