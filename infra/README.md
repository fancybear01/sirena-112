# Infrastructure

Локальная инфраструктура проекта:

- PostgreSQL 12+;
- Asterisk как локальный SIP-сервер (`infra/asterisk`, см. README там);
- контейнеры сервисов;
- локальные модели и записи разговоров;
- мониторинг, журналы и резервные копии.

Облачные зависимости не должны быть обязательны для демонстрационной сборки.
