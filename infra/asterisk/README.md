# Asterisk

Минимальная контрольная точка телефонии:

1. Зарегистрировать внутренний SIP-номер обучающегося.
2. Инициировать входящий вызов через ARI.
3. Создать мост с `externalMedia`.
4. Передать RTP в Go Media Gateway.
5. Вернуть тестовый аудиопоток в вызов.
6. Корректно завершить звонок и сохранить запись.

Конфигурационные файлы Asterisk добавляются после первого SIP-спайка.
