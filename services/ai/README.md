# AI Service

Python-сервис с локальными моделями.

Ответственность:

- генерация сценариев и эталонов;
- моделирование поведения абонента;
- классификация происшествия;
- анализ свободного текста и транскрипта;
- рекомендации по результатам занятия;
- STT/TTS либо адаптеры к локальным речевым процессам.

Сервис получает контекст через Kotlin Core и не имеет прямого доступа к
основной схеме PostgreSQL.
