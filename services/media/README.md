# Media Gateway

Go-сервис для локального телефонно-аудиоконтура.

Интеграции:

- Asterisk: ARI по HTTP/WebSocket и аудио по RTP;
- Kotlin Core: REST-команды и WebSocket-события;
- Python Speech: потоковый STT/TTS по gRPC или бинарному WebSocket.

Сервис не обращается к PostgreSQL и не вычисляет учебную оценку.
